  HashCortx — Workspaces Guide
  v3.0.0  ·  github.com/Hash-7777/HashCortX
══════════════════════════════════════════════════════════════

HashCortx has eight workspaces, plus Agents, Split and
Connections. They share your keys, your local models and the
model menu, so you can move between them freely.


──────────────────────────────────────────────────────────────
1. CHATS
──────────────────────────────────────────────────────────────
Talk to any model you have a key for: Groq, Gemini, OpenAI,
Anthropic, Moonshot (Kimi), DeepSeek, Mistral, Cerebras,
SambaNova, OpenRouter and NVIDIA. Or run a model on this
computer through Ollama or another local model app.

Chats keep projects, attachments, memory (with its own switch
in Settings) and a local knowledge base. Type / in the box for
commands. When a model fails, the next one is tried on the
same side you chose: this computer, or the cloud.


──────────────────────────────────────────────────────────────
2. HASHCODER
──────────────────────────────────────────────────────────────
A coding agent on your real project: file tree, diffs with
Keep and Undo, a terminal, and attachments by paste or drop.

Around the model sits a harness. HashCortx decides what the
model is shown, what it may do without asking, and what it
has to prove before a run may end:

  • It runs your project's tests after a change, reads a
    changed website the way a browser would, and sends itself
    back for what it left unfinished.
  • A request with several asks is checked ask by ask.
  • A model under 5B works in light mode: it writes whole
    files and HashCortx does the tool work for it. Larger and
    cloud models get a map of your code and a second look at
    larger changes.

The menu beside the box sets how much it may do without
asking: Manual (the start), Accept edits, or Auto.


──────────────────────────────────────────────────────────────
3. AGENT SWARM
──────────────────────────────────────────────────────────────
Teams of agents on any mix of models. Build a team on the
canvas, start from a template, or describe the task and have
one designed for it, sized to the work and to your computer.

What the team owes is worked out from your request. A task
about you asks first for the details only you can give. The
Result holds each agent's part, every file and every version,
opens a site in your browser, runs again only the agents that
did not finish, and exports a report for finding bugs.


──────────────────────────────────────────────────────────────
4. 3D FORGE
──────────────────────────────────────────────────────────────
Describe a part and get a dimensioned solid, in millimetres.
Exports STL, OBJ, 3MF and STEP, with a printability report.


──────────────────────────────────────────────────────────────
5. ERP
──────────────────────────────────────────────────────────────
Opens on an empty business app you can type into straight
away. Tell its agent about your business and it builds the
app: records, stages and books, exported as one HTML file.
Ask it to change the design, to record what happened, or to
answer from your records; you see each change before it is
made, and can undo it. It can also read a connected system.


──────────────────────────────────────────────────────────────
6. FINANCE
──────────────────────────────────────────────────────────────
Attach a statement, CSV, PDF or XLSX, or type your figures.
The model lists the figures; the app does every sum, so every
card, chart and total agrees. Edit a figure and everything
updates. It can also report from a connected system.


──────────────────────────────────────────────────────────────
7. SANDBOX
──────────────────────────────────────────────────────────────
Paste untrusted code or text, and a team of agents inspects
it for malware, prompt injection and suspicious logic.


──────────────────────────────────────────────────────────────
8. VIRTUAL OS
──────────────────────────────────────────────────────────────
A simulated desktop with its own files, in which an agent
builds a project.


──────────────────────────────────────────────────────────────
AGENTS, SPLIT AND CONNECTIONS
──────────────────────────────────────────────────────────────
Agents: nine built-in specialists — HashCortx, HashCortx
Lite, Researcher, Deep Research, Coder, URL Reader, Published
Papers Researcher, Medical Lexi-Check and ATS CV Auditor —
and a builder for your own.

Split: one prompt, answered by two models side by side.

Connections: a business system connected over MCP, from
Settings → Connections. Odoo, GitHub, Stripe and Supabase are
ready-made. Reading asks once; every change asks every time.


══════════════════════════════════════════════════════════════
  GETTING STARTED
══════════════════════════════════════════════════════════════

  • Add a key in Settings → API keys and press Test, or set
    up a model on this computer in Settings → Local model.

  • There is no HashCortx server. Your chats, keys and files
    stay on this computer, and each request goes only to the
    model, search or system it is for. docs/SECURITY.md lists
    every address.

  • Shortcuts: Cmd/Ctrl + Shift + C opens or leaves
    HashCoder, Cmd/Ctrl + Shift + N starts a new chat, and
    Cmd/Ctrl + K opens the model menu.
