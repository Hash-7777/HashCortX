Run a model on this computer. It costs nothing, needs no key, and not one word leaves the machine. Four steps — this page checks each one for you.
  1. 1 Get Ollama Checking…

    Ollama is the free program that actually runs the model. HashCortX only talks to it over your own network loopback — it never installs it, never changes your system files, and never asks for your password.

    Nothing to do for most people — the address below is where Ollama listens by default. Change it only if the model runs on another machine on your network.

    Full endpoint settings live in General.

  4. 4 Use it Checking…

    Close this window and choose your model in the picker at the top of the screen. Local models sit above the cloud ones in the list.

    They work in Chat, Coder, Swarm, Forge and the knowledge base. With one downloaded, the whole app runs with the network off — the only exception is the Python sandbox, which fetches its runtime the first time you use it.
